# Regras

O projeto separa regras oficiais e locais em `rules/`. Regras que dependem de relatórios ainda não disponíveis ficam explicitamente desativadas. Na base atual de acompanhamento do território, o motor ativo limita-se a controles operacionais e de qualidade de dados (identificadores ausentes, vínculo familiar incompleto e grupos etários para organização), sem inferir diagnóstico ou condição clínica.
